# جوِّد — تعلّم التلاوة والتجويد

تطبيق iPhone أصلي (SwiftUI) لتعلّم التلاوة بالاستماع والتكرار خلف الشيخ محمد صديق المنشاوي.

## المرحلة الأولى: المصحف والمشغّل
1. فهرس السور والأجزاء، مع البحث بالاسم أو الرقم.
2. صفحة التلاوة بخط Amiri Quran، سطوراً متصلة كالمصحف، مع علامات الوقف ورقم كل آية.
3. المشغّل: يتوقف بعد كل آية لتكرّرها (بطول الآية، أو مرة ونصفاً، أو مدة ثابتة)، ويكرّر كل آية العدد الذي تختاره، وينتقل تلقائياً أو حين تضغط «التالي».
4. السرعة ٠٫٧٥ و١ و١٫٢٥ دون تغيير طبقة الصوت، ونطاق آيات تختاره.
5. تظليل الآية الحالية والكلمة التي يقرؤها الشيخ.
6. التشغيل والشاشة مقفلة، مع أزرار التحكم في شاشة القفل.
7. ثلاث تلاوات: المرتّل والمجوّد آيةً آية، والمصحف المعلّم (ترديد الأطفال) للاستماع إلى السورة كاملة.
8. تنزيل السور للاستماع دون إنترنت، وحفظ آخر موضع، ونسبة الإنجاز لكل سورة وجزء.
9. الوضع الليلي، وحجم خط المصحف.

## البناء بدون Mac
يبني GitHub Actions التطبيق على أجهزة Mac مجانية مع كل دفعة إلى `main`:
- ملف `Jawwid.ipa` على الفرع `ipa`.
- سجلّ البناء على الفرع `logs`.
- صور المحاكي على الفرع `shots` حين تحتوي رسالة الدفعة على `[shots]`.

## التثبيت على الآيفون
1. نزّل `Jawwid.ipa` من الفرع `ipa`.
2. ثبّته بـ AltStore أو Sideloadly بحساب Apple. التوقيع المجاني يصلح ٧ أيام ثم يُجدَّد.
3. الإعدادات ← عام ← إدارة الأجهزة والـVPN ← وثّق حسابك.

بعد قبول حساب المطوّر يمكن نشره عبر TestFlight ثم App Store.

## البيانات
البيانات المضمّنة في `App/Resources/Data` مبنية من مصادرها الرسمية:
1. يجلبها سير العمل «Fetch source data» إلى الفرع `rawdata`.
2. ثم: `python3 tools/build_data.py --raw <مجلد rawdata>`

يتحقق السكربت من تطابق نص تنزيل في ملفي XML والنص حرفاً حرفاً، ومن عدد الآيات وحدود الأجزاء مقابل بيانات تنزيل. المصادر وتراخيصها في [CREDITS.md](CREDITS.md).
